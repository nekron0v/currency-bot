# Currency Bot

Telegram-бот: курсы валют, графики, подписки, утренний дайджест, OCR чеков.

## Возможности

- Inline-режим: `@ваш_бот 100 USD RUB`, `@ваш_бот USD`, `@ваш_бот USD 7`
- Подписки на порог: `/subscribe USD > 95`
- Утренний дайджест в 9:00 МСК: `/digest_on`
- График за N дней (ASCII-спарклайн): `/chart USD 14`
- OCR чеков: пришлите фото, бот распознает сумму

## Источники курсов

- `open.er-api.com` — основной, обновление раз в час
- `cbr-xml-daily.ru` — резервный + архив для графиков

## Переменные окружения

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather |
| `WEBHOOK_URL` | Публичный URL Render (задаётся автоматически) |
| `OCRSPACE_KEY` | Ключ OCR.space (по умолчанию `helloworld`) |
